# 低压电气保护与断路器选型速查

## 一、保护类型

| 保护类型 | 功能 | 常用元件 |
|---------|------|---------|
| 短路保护 | 大电流瞬时切断 | 瞬时脱扣（电磁式） |
| 过载保护 | 过负荷延时切断 | 热脱扣（双金属片） |
| 漏电保护 | 人身触电防护 | RCD（剩余电流保护） |
| 欠压保护 | 电压过低切断 | 欠压脱扣器 |
| 过压保护 | 电压过高切断 | 浪涌保护器（SPD） |

## 二、断路器选型速查表

| 回路类型 | 额定电流 | 脱扣特性 | 分断能力 |
|---------|---------|---------|---------|
| 照明回路 | 16~32A | C 型（5~10In） | 6kA |
| 插座回路 | 20~40A | C 型 | 6kA |
| 空调回路 | 25~63A | D 型（10~20In） | 10kA |
| 动力回路 | 63~250A | D 型 | 15~35kA |
| 配电干线 | 250~630A | 电子式 | 35~65kA |
| 消防回路 | 按负荷 | 仅短路保护 | ≥10kA |

## 三、选择性配合

- 上下级断路器选择性系数 ≥ 1.2
- 保证 Icu（上级） ≥ 1.2 × Icu（下级安装点）
- 时间选择性：上级延时 0.1~0.5s
- 电流选择性：上级瞬时 > 下级短路电流

## 四、漏电保护（RCD）

| 场景 | 额定动作电流 | 动作时间 |
|------|------------|---------|
| 人身安全 | 30mA | ≤ 0.1s |
| 防火（总保护） | 100~300mA | ≤ 0.3s |
| 浴室/游泳池 | 10mA | ≤ 0.1s |
| 医疗场所 | 6mA | ≤ 0.04s |

## 五、电涌保护器（SPD）分级

| 级别 | 安装位置 | 标称放电电流 |
|------|---------|------------|
| I 级 | 总配电箱（LPZ0→1） | ≥ 25kA（10/350μs） |
| II 级 | 分配电箱（LPZ1→2） | ≥ 40kA（8/20μs） |
| III 级 | 设备端（LPZ2→3） | ≥ 10kA（8/20μs） |
