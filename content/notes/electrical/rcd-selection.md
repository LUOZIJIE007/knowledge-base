# RCD漏电保护器选型与应用

## 一、RCD 基本参数

| 参数 | 含义 | 常用值 |
|------|------|--------|
| IΔn | 额定剩余动作电流 | 10/30/100/300/500mA |
| IΔn0 | 不动作电流 | 0.5 × IΔn |
| t | 动作时间 | ≤ 0.04s / ≤ 0.1s / ≤ 0.3s |
| In | 额定电流 | 16~630A |
| 极数 | 1P+N / 2P / 3P / 4P | 按回路选择 |

## 二、RCD 选型速查表

| 应用场景 | IΔn | 动作时间 | 极数 | 备注 |
|---------|-----|---------|------|------|
| 人身安全保护 | 30mA | ≤ 0.1s | 1P+N/2P | 所有插座回路 |
| 浴室/游泳池 | 10mA | ≤ 0.1s | 2P | 潮湿场所 |
| 医疗场所 | 6mA | ≤ 0.04s | 2P | IT 系统 |
| 防火保护（总保护） | 100~300mA | ≤ 0.3s | 4P | 总配电箱 |
| 防火保护（分级） | 300~500mA | ≤ 0.3s | 4P | 分配电箱 |
| 电气火灾监控 | 500mA~1A | 延时 | 4P | 监测型 |

## 三、RCD 分类

| 类型 | 适用波形 | 应用 |
|------|---------|------|
| AC 型 | 纯正弦交流 | 照明/普通负荷 |
| A 型 | 交流+脉动直流 | 变频器/调光器/UPS |
| B 型 | 交流+直流+高频 | 光伏/电动车充电/变频 |
| S 型（选择性） | 延时动作 | 上下级配合 |
| 短延时型 | 0.1~0.5s | 防火保护 |

## 四、RCD 安装要点

### 4.1 安装位置
- **必须装**：所有插座回路、潮湿场所、室外回路
- **总配电箱**：设防火 RCD（300mA 延时）
- **分配电箱**：设人身安全 RCD（30mA）
- **末端**：每个插座回路独立 RCD

### 4.2 级联配合
```
总配电箱（300mA，t≤0.3s）
  └─ 分配电箱（100mA，t≤0.15s）
       └─ 末端回路（30mA，t≤0.1s）
```
- 上下级额定动作电流比 ≥ 3:1
- 上下级动作时间级差 ≥ 0.1s

### 4.3 接线要求
- RCD 后的 N 线不得重复接地
- PE 线不得穿过 RCD 的零序互感器
- RCD 负荷侧 N 线不得与 PE 线混接

## 五、常见故障与处理

| 故障现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 频繁跳闸 | 线路漏电/绝缘老化 | 测绝缘电阻，查漏电点 |
| 合不上闸 | 负荷侧短路/漏电 | 排除故障后合闸 |
| 误动作 | 浪涌/谐波干扰 | 更换 A/B 型 RCD |
| 不动作 | RCD 损坏/接线错 | 按测试按钮，更换 RCD |
| 一送电就跳 | 接线错误/严重漏电 | 检查 N/PE 是否混接 |

## 六、注意事项

- RCD **每月按一次**测试按钮验证动作
- **不能代替**短路保护和过载保护（需配断路器）
- 消防回路**不设漏电保护**（GB 50054 §6.1.2）
- 变频器后必须用 **A 型**或 **B 型** RCD
- 施工后需测试 RCD 动作特性（IΔn、t）
