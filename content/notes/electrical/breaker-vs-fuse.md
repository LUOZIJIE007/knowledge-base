# 断路器与熔断器对比速查

## 一、核心对比表

| 对比项 | 断路器（MCB/MCCB/ACB） | 熔断器（Fuse） |
|--------|----------------------|--------------|
| **保护功能** | 短路+过载+漏电(可选) | 仅短路+过载 |
| **动作速度** | 10~30ms（瞬时） | 2~5ms（更快） |
| **分断能力** | 6~65kA | 50~200kA（更高） |
| **恢复使用** | 可重复合闸 | 熔断后需更换 |
| **选择性** | 可调（电子式） | 天然选择性好 |
| **成本** | 较高 | 低 |
| **体积** | 较大 | 紧凑 |
| **寿命** | 机械寿命 1~2 万次 | 一次性 |
| **维护** | 低 | 需备件 |
| **智能化** | 可带通信/测量 | 无 |

## 二、选用建议

| 场景 | 推荐 | 原因 |
|------|------|------|
| 一般配电 | 断路器 | 功能全面，维护方便 |
| 消防回路 | 断路器（仅短路保护） | 规范要求 |
| 电动机保护 | 断路器 + 热继电器 | 过载+短路+断相 |
| 变压器保护 | 熔断器 + 断路器 | 短路容量大 |
| 光伏/直流 | 熔断器（直流型） | 分断能力强 |
| 电子设备 | 熔断器 | 限流特性好 |
| 需要遥控/监测 | 断路器 | 可加附件 |
| 成本敏感 | 熔断器 | 便宜 |

## 三、动作特性对比

### 断路器脱扣特性
| 曲线 | 瞬时脱扣 | 适用负荷 |
|------|---------|---------|
| B 型 | 3~5 In | 线路保护 |
| C 型 | 5~10 In | 照明/插座 |
| D 型 | 10~20 In | 动力/变压器 |

### 熔断器特性
| 类型 | 特性 | 适用 |
|------|------|------|
| gG | 一般用途 | 配电线路 |
| aM | 电动机保护 | 电动机回路 |
| gR/gS | 半导体保护 | 变频器/整流器 |

## 四、配合使用方案（最佳实践）

```
电源 → 熔断器（短路保护）→ 断路器（过载/漏电）→ 负荷
```
- 熔断器承担短路大电流分断
- 断路器提供过载保护和可操作性
- 两者配合实现完全选择性

## 五、常见误区

1. **误区**：熔断器比断路器安全 → 熔断器分断能力高但功能单一
2. **误区**：断路器可完全替代熔断器 → 大短路容量场合熔断器更优
3. **误区**：熔断器不需要选择性 → 熔断器间也有级差配合（1.6:1）
4. **误区**：消防回路用普通断路器 → 消防回路只设短路保护（不设过载）
