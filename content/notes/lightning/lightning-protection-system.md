# 建筑防雷接地系统设计要点

## 一、防雷等级分类

| 等级 | 判定条件 | 年雷击次数 |
|------|---------|-----------|
| **第一类** | 炸药库、火工品库 | N ≥ 0.05 |
| **第二类** | 高层建筑、人员密集场所 | 0.05 > N ≥ 0.01 |
| **第三类** | 一般建筑 | N < 0.01 |

**N = Ng × Ae**（Ng 为地闪密度，Ae 为等效面积）

## 二、防雷系统构成

### 2.1 外部防雷
- **接闪器**：避雷针、避雷带、避雷网
  - 避雷带：Φ10 镀锌圆钢或 25×4 镀锌扁钢
  - 保护范围：滚球法计算（一类 h=30m，二类 h=45m，三类 h=60m）
- **引下线**：
  - 优先利用建筑钢筋（Φ≥16mm 两根或 Φ≥12mm 四根）
  - 独立引下线间距：一类 ≤12m，二类 ≤18m，三类 ≤25m
- **接地装置**：基础钢筋自然接地体，接地电阻 ≤1Ω（联合接地）

### 2.2 内部防雷
- **等电位连接**：总等电位（MEB）+ 局部等电位（LEB）
- **电涌保护器（SPD）**：
  - 电源系统：三级保护（I 级 → II 级 → III 级）
  - 信号系统：信号 SPD + 同轴 SPD
- **安全间距**：引下线与金属管线间距 ≥ 0.3m

## 三、接地系统

### 3.1 接地类型
| 类型 | 符号 | 接地电阻 |
|------|------|---------|
| 工作接地 | — | ≤4Ω |
| 保护接地 | PE | ≤4Ω |
| 防雷接地 | — | ≤10Ω（独立） |
| 联合接地 | — | ≤1Ω |
| 防静电接地 | — | ≤100Ω |

### 3.2 TN-S 系统（最常用）
- PE 线与 N 线严格分开
- 火线 L1/L2/L3 + 中性线 N + 保护地线 PE
- 所有金属外壳接 PE 线

## 四、等电位连接

- **MEB（总等电位）**：进线配电箱处，连接 PE 干线、金属管道、建筑钢筋
- **LEB（局部等电位）**：卫生间、浴室、游泳池，连接局部金属构件
- **SPD 安装**：LPZ0→1 交界处装 I 级 SPD，后续分级

## 五、重要规范

- **GB 50057-2010** 建筑物防雷设计规范
- **GB 50343-2012** 建筑物电子信息系统防雷技术规范
- **GB 50169-2016** 电气装置安装工程接地装置施工及验收规范
- **GB 51348-2019** 民用建筑电气设计标准
