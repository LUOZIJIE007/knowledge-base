# 弱电智能化系统设计要点

## 一、弱电系统分类

| 系统 | 功能 | 常用标准 |
|------|------|---------|
| **综合布线** | 数据/语音传输 | GB 50311 |
| **安防监控** | 视频监控、入侵报警 | GB 50395 |
| **门禁系统** | 出入控制、考勤 | GA/T 394 |
| **楼宇自控（BA）** | 暖通/照明/电梯控制 | GB/T 50314 |
| **消防报警（FA）** | 火灾探测与联动 | GB 50116 |
| **综合安防（SA）** | 安防集成管理 | GB 50394 |
| **通信网络** | 电话、网络、WiFi | GB 50311 |
| **会议系统** | 音视频、同声传译 | GB 50799 |
| **广播系统** | 背景音乐、紧急广播 | GB 50526 |

## 二、综合布线系统

### 2.1 系统构成（6 个子系统）
1. **工作区子系统**：信息插座 + 跳线
2. **水平子系统**：水平线缆（Cat5e/Cat6/Cat6A）
3. **管理子系统**：配线架、跳线管理
4. **垂直子系统**：主干光缆/大对数电缆
5. **设备间子系统**：主配线架、交换机
6. **建筑群子系统**：室外管道、光缆

### 2.2 设计要点
- 水平线缆长度 ≤ 90m（不含跳线）
- 信息插座距地 300mm（办公区）或 1200mm（酒店客房）
- 管线弯曲半径 ≥ 6 倍管径
- 强弱电间距 ≥ 300mm（交叉时 ≥ 50mm）

## 三、视频监控系统

### 3.1 前端设计
- **摄像头类型**：枪机（固定）、球机（旋转）、半球（室内）
- **分辨率**：≥ 200 万像素（1080P）为基本要求
- **覆盖原则**：无死角、人脸可识别（≥ 50px）
- **安装高度**：室内 2.5~4m，室外 3.5~10m

### 3.2 传输设计
- 摄像头 → 接入交换机（PoE 供电，网线 ≤ 100m）
- 接入交换机 → 汇聚交换机（光缆）
- 汇聚交换机 → 核心交换机/NVR

### 3.3 存储设计
- 存储容量 = 摄像头数 × 码率 × 时间 / 8
- 一般 200 万像素 H.265 码率 4Mbps
- 保存时间 ≥ 30 天（重点场所 ≥ 90 天）

## 四、门禁系统

- **识别方式**：IC 卡、人脸、指纹、二维码
- **电锁类型**：磁力锁（断电开）、电插锁（断电开/关）
- **消防联动**：火灾时强制开门（与消防系统联动）
- **设计要求**：消防通道门禁必须能紧急开启

## 五、楼宇自控系统（BA）

- **控制对象**：空调、给排水、照明、电梯、变配电
- **控制方式**：DDC 直接数字控制
- **通信协议**：BACnet、Modbus、LonWorks
- **监控点位**：AI/AO/DI/DO 四种

## 六、重要规范

- **GB 50311-2016** 综合布线系统工程设计规范
- **GB 50395-2007** 视频安防监控系统工程设计规范
- **GB 50314-2015** 智能建筑设计标准
- **GB/T 50314-2015** 智能建筑设计标准
- **GB 50394-2007** 入侵报警系统工程设计规范
