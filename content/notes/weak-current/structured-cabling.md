# 综合布线系统设计要点

## 一、系统构成（六大部分）

| 子系统 | 位置 | 功能 |
|--------|------|------|
| 工作区 | 用户端 | 信息插座/跳线 |
| 水平子系统 | 楼层内 | 插座→配线架（≤ 90m） |
| 干线子系统 | 竖井 | 楼层配线架→设备间 |
| 设备间 | 主机房 | 核心交换机/服务器 |
| 进线间 | 建筑入口 | 运营商接入 |
| 管理间 | 楼层弱电井 | 楼层配线架/交换机 |

## 二、线缆选择

| 类型 | 速率 | 带宽 | 最大距离 | 适用 |
|------|------|------|---------|------|
| Cat5e | 1Gbps | 100MHz | 100m | 基本办公 |
| Cat6 | 1Gbps | 250MHz | 100m | 标准办公 |
| Cat6A | 10Gbps | 500MHz | 100m | 高速办公 |
| Cat7 | 10Gbps | 600MHz | 100m | 数据中心 |
| OM3 光纤 | 10Gbps | — | 300m | 楼层主干 |
| OM4 光纤 | 10Gbps | — | 400m | 楼层主干 |
| OS2 光纤 | 100Gbps | — | 10km | 建筑群 |

## 三、水平布线设计

### 3.1 距离限制
- 插座→配线架：≤ **90m**（永久链路）
- 跳线两端各 ≤ **5m**，总长 ≤ **100m**
- 光纤水平：≤ 90m（多模）

### 3.2 管线设计
| 敷设方式 | 管径要求 | 弯曲半径 |
|---------|---------|---------|
| 暗敷穿管 | 管截面利用率 ≤ 40% | ≥ 6D |
| 桥架/线槽 | 填充率 ≤ 50% | ≥ 6D |
| 地板下 | 线槽封闭 | ≥ 6D |

### 3.3 信息点配置
| 场景 | 信息点/工位 | 插座高度 |
|------|-----------|---------|
| 开放办公 | 2~3 个 | 地面 300mm |
| 独立办公室 | 3~4 个 | 墙面 300mm |
| 会议室 | 4~6 个 | 桌面/地面 |
| 前台 | 4~6 个 | 台面 |

## 四、干线子系统

- **数据主干**：光纤（OM3/OS2），每层至少 12 芯
- **语音主干**：大对数电缆（50/100 对）
- **备份冗余**：主干光纤双路由
- 主干光纤预留 50% 冗余

## 五、设备间/管理间

| 要素 | 要求 |
|------|------|
| 温度 | 18~28℃ |
| 湿度 | 30%~70% |
| 供电 | UPS，双回路 |
| 接地 | 联合接地 ≤ 1Ω |
| 防火 | 门甲级，线缆阻燃 |
| 面积 | ≥ 10m²（主设备间） |

## 六、PoE 供电设计

| 标准 | 功率 | 最大距离 | 适用 |
|------|------|---------|------|
| 802.3af | 15.4W | 100m | IP电话/AP |
| 802.3at | 30W | 100m | 云台摄像机 |
| 802.3bt | 60~90W | 100m | 球机/屏幕 |

- 网线电阻 ≤ 12.5Ω（100m Cat6）
- 超过 90W 需用专用 PoE 交换机
- 网线截面越小损耗越大（Cat6 比 Cat5e 好）

- [ ] 接地连续性
