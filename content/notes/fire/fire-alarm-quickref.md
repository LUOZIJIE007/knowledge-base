# 火灾自动报警与联动控制速查

## 一、报警系统组成

- **火灾报警控制器**：接收/显示/传递火灾报警信号
- **消防联动控制器**：控制消防设备
- **手动报警按钮**：每个防火分区 ≥ 1 个，距地 1.3~1.5m
- **声光报警器**：每个防火分区 ≥ 1 个
- **消防广播**：每个防火分区独立分区
- **消防电话**：消防泵房、发电机房、配电室等设固定电话

## 二、联动逻辑表

| 触发条件 | 联动动作 |
|---------|---------|
| 同一防护区 2 个独立探测器 | 确认火灾 |
| 1 个探测器 + 1 个手报 | 确认火灾 |
| 湿式报警阀压力开关 | 启动喷淋泵 |
| 消火栓按钮 | 启动消火栓泵 |
| 任一水流指示器 | 报警显示 |
| 任一防火阀 70℃ | 关闭空调机组 |
| 排烟防火阀 280℃ | 停止排烟风机 |

## 三、消防电源监控

- 消防设备电源监控系统（GB 50116）
- 监控消防电源电压、电流、开关状态
- 故障报警：断路、过压、欠压

## 四、电气火灾监控

- 剩余电流式电气火灾监控探测器（GB 50116）
- 报警值：300~500mA
- 测温式电气火灾监控：电缆接头、母线槽
- 独立于火灾自动报警系统

## 五、应急疏散

- 应急照明控制器（集中电源型 A 型）
- 疏散指示标志：距地 1m 以下
- 应急照明持续时间：≥ 1.0h（一般）/ ≥ 1.5h（高层）
- 系统应急启动后 5s 内转入蓄电池供电
