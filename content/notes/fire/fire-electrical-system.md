# 建筑消防电气系统设计要点

## 一、火灾自动报警系统

### 1.1 系统形式
| 形式 | 适用场景 |
|------|---------|
| **区域报警** | 小型建筑 |
| **集中报警** | 大中型建筑（最常用） |
| **控制中心** | 大型建筑群、超高层 |

### 1.2 探测器选型
| 探测器类型 | 适用场所 | 不适用场所 |
|-----------|---------|-----------|
| **感烟（点型）** | 办公室、卧室、走道 | 厨房、车库、浴室 |
| **感温（点型）** | 厨房、车库、锅炉房 | 走道、办公室 |
| **火焰探测器** | 油库、化工车间 | 有遮挡的场所 |
| **线型感温** | 电缆隧道、皮带廊 | — |
| **可燃气体** | 厨房、燃气表间 | — |

### 1.3 探测器布置
- 保护面积：感烟 60~80m²（h≤6m），感温 20~30m²
- 安装间距：感烟 ≤ 6.7m（h≤6m），感温 ≤ 4.4m
- 距墙距离：≤ 探测器安装间距的 1/2
- 距空调送风口：≥ 1.5m

## 二、消防联动控制

### 2.1 联动逻辑
```
火灾确认 → 报警控制器
  → 启动声光报警
  → 切断非消防电源
  → 电梯迫降首层
  → 启动排烟风机/正压送风机
  → 打开排烟阀/正压送风口
  → 关闭防火阀/防火门
  → 启动消防水泵
  → 切断空调系统
  → 启动应急照明
  → 消防广播播报疏散指令
```

### 2.2 消防电源
- **一级负荷**：超高层、大型公共建筑
- **二级负荷**：高层住宅、中型公共建筑
- 消防设备供电：双回路 + UPS/EPS（切换时间 ≤ 5s）
- 消防配电线路：矿物绝缘电缆或耐火电缆

## 三、消防应急照明与疏散

- **应急照明**：地面照度 ≥ 1.0lx（走道），≥ 3.0lx（楼梯间）
- **疏散指示**：距地 1m 以下，间距 ≤ 20m（走道）
- **持续供电时间**：≥ 1.0h（一般）、≥ 1.5h（高层/人员密集）
- **A 型应急照明**：集中电源型（最常用）

## 四、消防广播系统

- 功率放大器容量 = 1.5 × 广播总功率
- 扬声器间距 ≤ 25m（走道），距端墙 ≤ 12.5m
- 紧急广播优先于背景音乐（强制切换）
- 广播分区与防火分区一致

## 五、防火卷帘

- 一步下降：烟感动作 → 降至 1.8m（疏散通道）
- 二步下降：温感动作 → 降到底（非疏散通道）
- 两侧均设手动启停按钮

## 六、重要规范

- **GB 50116-2013** 火灾自动报警系统设计规范
- **GB 50166-2019** 火灾自动报警系统施工及验收标准
- **GB 51309-2018** 消防应急照明和疏散指示系统技术标准
- **GB 50016-2014（2018 版）** 建筑设计防火规范
- **GB 50974-2014** 消防给水及消火栓系统技术规范
