# 民用建筑电气核心规范速查

## 一、规范体系总览

| 规范编号 | 名称 | 核心内容 |
|---------|------|---------|
| **GB 51348-2019** | 民用建筑电气设计标准 | 总纲，替代 JGJ 16 |
| **GB 50052-2009** | 供配电系统设计规范 | 供电电压、负荷分级 |
| **GB 50054-2011** | 低压配电设计规范 | 配电设计、保护 |
| **GB 50057-2010** | 建筑物防雷设计规范 | 防雷等级、措施 |
| **GB 50116-2013** | 火灾自动报警系统设计规范 | 报警、联动 |
| **GB 50311-2016** | 综合布线系统工程设计规范 | 弱电布线 |
| **GB 50016-2014** | 建筑设计防火规范 | 消防电气要求 |
| **GB 50343-2012** | 建筑物电子信息系统防雷技术规范 | SPD、等电位 |

## 二、负荷分级（GB 50052）

| 等级 | 适用建筑 | 供电要求 |
|------|---------|---------|
| **一级** | 超高层、大型医院、交通枢纽 | 双重电源 + 应急电源 |
| **二级** | 高层住宅、中型公共建筑 | 双回路供电 |
| **三级** | 一般建筑 | 单回路供电 |

## 三、关键设计参数速查

### 3.1 电压偏差
- 照明：+5% / -10%（GB 50054）
- 动力：±5%
- 电动机启动：电压降 ≤ 15%

### 3.2 照度标准（GB 50034）
| 场所 | 标准照度（lx） |
|------|---------------|
| 办公室 | 300~500 |
| 会议室 | 300~500 |
| 走道 | 50~100 |
| 卫生间 | 100~200 |
| 车库 | 30~75 |
| 楼梯间 | 30~75 |

### 3.3 插座设计
- 办公室：每 5m² 一个插座（距地 300mm）
- 客房：床头 + 书桌 + 卫生间（防溅型）
- 厨房：操作台每 600mm 一个（带开关）
- 空调：壁挂机 16A 单独回路，柜机 32A

## 四、线路敷设要求

| 场景 | 敷设方式 | 保护要求 |
|------|---------|---------|
| 暗敷 | 穿管暗敷（PVC/SC） | 保护层 ≥ 15mm |
| 明敷 | 金属线槽/桥架 | 接地可靠 |
| 竖井 | 金属桥架/梯架 | 每层封堵 |
| 消防 | 金属管/矿物绝缘电缆 | 耐火 2h |
| 室外 | 直埋/穿管 | 防腐、防水 |

## 五、等电位连接（GB 50057）

- **MEB**：进线处，连接 PE、金属管、建筑钢筋
- **LEB**：卫生间，连接金属构件、PE 线
- 接地电阻要求：联合接地 ≤ 1Ω

## 六、节能设计（GB 50034 / GB 51348）

- 照明功率密度（LPD）限值：办公 ≤ 8W/m²
- LED 光源为主，显色指数 Ra ≥ 80
- 公共区域照明控制：声控/光控/时控/智能控制
- 变压器负载率：60%~80% 为经济运行区

## 七、审查要点清单

- [ ] 负荷分级是否正确
- [ ] 供电电源是否满足等级要求
- [ ] 断路器选择性配合是否校验
- [ ] 线缆截面是否满足载流量和压降
- [ ] 防雷等级和 SPD 配置是否匹配
- [ ] 等电位连接是否完整
- [ ] 消防电源是否独立
- [ ] 照度和 LPD 是否满足节能要求
